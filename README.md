# Meesho Sale — Website Starter

Responsive ecommerce website + Express demo API. Android app files are intentionally excluded.

## Requirements
Install Node.js 20+ and npm.

## Run backend
```bash
cd server
npm install
npm run dev
```
API defaults to http://localhost:4000

## Run website
Open another terminal:
```bash
cd web
npm install
npm run dev
```
Open the URL Vite prints, usually http://localhost:5173.

## Included
- Product listing, search and category filters
- Add-to-cart and quantity controls
- Delivery form and demo order API
- Responsive mobile/desktop layout

## Before launch
This is a demo starter, not a production-ready store. Add a persistent database, secure customer/admin authentication, protected admin routes, payment gateway, shipping integration, HTTPS hosting, and privacy/terms/returns policies. Do not collect card numbers directly. Original starter code/design; not affiliated with Meesho.
